Shadow of the Beast III — browser runner

This page runs the real Amiga game on a WebAssembly Amiga emulator. It ships no game or ROM data. You must select your own legally owned Kickstart ROM and the game media. The game is © 1992 Psygnosis.

Emulator: vAmigaWeb (GPLv3). Place its build (js/vAmigaWeb_player.js, vAmiga.js, vAmiga.wasm) in ./vamigaweb/ before serving this page. See web/README.md.
